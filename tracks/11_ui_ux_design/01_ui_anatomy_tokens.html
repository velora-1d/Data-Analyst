2. Ensiklopedia & Taksonomi 108 Komponen UI Lengkap

Di dalam rekayasa desain antarmuka industri modern (*Apple Human Interface Guidelines, Google Material Design 3, Radix UI, Shopify Polaris, Tailwind UI*), tidak ada elemen yang dibuat secara sembarangan. Setiap tombol, kotak input, notifikasi, hingga tata letak memiliki nama baku, peran fungsi UX, standar aksesibilitas keyboard (WCAG 2.1 AA), dan aturan penempatan.

Berikut adalah 108 Komponen Antarmuka Digital Lengkap yang diklasifikasikan ke dalam 10 domain fungsional. Gunakan fitur pencarian cepat di bawah ini untuk mencari komponen apa pun seketika:

108 Komponen Aktif

1. Navigasi & Orientasi Pengguna (Wayfinding)

Komponen yang memandu pengguna mengetahui posisinya saat ini dan berpindah antar-layar tanpa disorientasi.

No Nama Komponen UI Definisi & Peran Fungsional UX Best Practice & Aksesibilitas (WCAG) Contoh Industri
1 Navbar (Top Navigation Bar) Pita horizontal utama di bagian atas viewport berisi brand, menu utama, pencarian, dan profil/CTA. Gunakan position: sticky; top: 0; dengan backdrop blur agar selalu dapat diakses saat scroll. Header portal Tokopedia, Stripe, GitHub.
2 Sidebar Navigation (Expanded) Panel navigasi vertikal (240px-280px) untuk aplikasi dengan banyak modul hirarkis. Kelompokkan menu dengan divider dan label kategori yang jelas (Grouping). Dashboard AWS Console, Cloudflare, Linear.
3 Navigation Rail (Collapsed) Sidebar ramping (64px) yang hanya menampilkan ikon vertikal untuk menghemat ruang kanvas kerja. Wajib berikan tooltip pada hover agar arti ikon tetap jelas bagi pengguna baru. VS Code sidebar, Figma toolbar, Slack workspace switcher.
4 Breadcrumbs Jejak remah roti horizontal penunjuk hierarki lokasi data (Home > Kategori > Sepatu). Gunakan pemisah non-teks atau panah halus dan beri atribut aria-current="page" pada item terakhir. Halaman produk Amazon, dokumentasi MDN Web Docs.
5 Tabs (Segmented Control) Pengalih konten selevel dalam satu kontainer viewport tanpa reload halaman. Gunakan role="tablist", role="tab", dan aria-selected="true" untuk aksesibilitas. Tab 'Overview' / 'Pull Requests' di GitHub.
6 Pagination Kontrol pemecah daftar data per lembar (< 1 2 3 ... 10 >) dengan tombol previous/next. Tampilkan jumlah total baris/halaman agar pengguna tahu estimasi volume data. Hasil pencarian Google Search, daftar transaksi bank.
7 Infinite Scroll Loader Pemicu pemuatan data otomatis saat pengguna scroll mendekati batas bawah kanvas. Berikan opsi 'Kembali ke Atas' dan jangan tempatkan tautan footer penting di bawahnya. Feed Twitter/X, Instagram, Pinterest.
8 Stepper / Wizard Indikator langkah berurutan (Langkah 1: Akun > 2: Alamat > 3: Pembayaran). Beri tahu status tiap langkah (Done, Active, Pending) dan simpan draf jika alur panjang. Checkout belanja Shopee, pendaftaran akun bank digital.
9 Bottom Navigation Bar Menu navigasi 3-5 ikon yang menempel di bagian bawah layar smartphone. Prioritaskan ikon yang paling sering diakses ibu jari (Natural Thumb Zone). Aplikasi mobile Gojek, Spotify, YouTube.
10 Floating Action Button (FAB) Tombol bulat melayang di pojok kanan-bawah layar pemicu aksi tunggal terpenting. Hanya boleh 1 FAB utama per layar agar tidak membingungkan hirarki aksi. Tombol 'Tulis Email Baru' di aplikasi Gmail mobile.
11 Speed Dial (Expandable FAB) FAB yang merekah mengeluarkan beberapa sub-tombol aksi terkait saat ditekan. Beri animasi rotasi 45 derajat pada ikon utama saat menu terbuka. Google Maps mobile (Laporkan Kejadian, Cari Tempat).
12 Skip to Content Link Tautan tersembunyi yang muncul saat tombol Tab pertama kali ditekan untuk bypass navbar. Wajib di setiap situs standar WCAG 2.1 AA untuk pengguna navigasi keyboard. Standar website pemerintahan dan enterprise aksesibel.
13 Mega Menu Dropdown lebar multi-kolom yang memuat seluruh katalog kategori besar sekaligus. Beri sedikit delay (150ms) pada mouseleave agar dropdown tidak tiba-tiba tertutup. Menu kategori Tokopedia, BestBuy, Ikea.
14 Tree View Struktur direktori pohon bertingkat yang dapat dibuka dan ditutup (expand/collapse). Dukung navigasi panah keyboard (ArrowUp, ArrowDown, ArrowRight/Left). File explorer VS Code, folder Google Drive.
15 Anchor Navigation (Table of Contents) Daftar navigasi cepat ke heading-heading spesifik di dalam satu artikel panjang. Pasangkan dengan IntersectionObserver (Scrollspy) untuk menandai heading yang sedang dibaca. Sidebar kanan dokumentasi Stripe, Wikipedia, Tailwind CSS.

2. Aksi & Pemicu Interaksi (Actions & Triggers)

Komponen yang diaktifkan pengguna untuk mengeksekusi fungsi, submit data, atau mengubah state sistem.

No Nama Komponen UI Definisi & Peran Fungsional UX Best Practice & Aksesibilitas (WCAG) Contoh Industri
16 Primary Button Tombol kontras tertinggi penentu aksi konversi terpenting dalam layar. Gunakan maksimal 1 tombol primer per viewport aktif untuk mencegah keraguan klik. 'Beli Sekarang', 'Daftar Akun', 'Simpan Perubahan'.
17 Secondary Button Tombol netral berbingkai tipis untuk aksi pendukung yang tidak menyelesaikan alur. Jangan gunakan warna mencolok; cukup warna netral surface dengan border kontras sedang. 'Simpan Draf', 'Lihat Preview', 'Kembali'.
18 Outline Button Tombol transparan dengan garis tepi halus sewarna tema brand. Sangat baik untuk tombol aksi tingkat kedua di sebelah tombol primer. Filter chip, navigasi halaman katalog.
19 Ghost / Text Button Tombol tanpa batas fisik; background hanya muncul saat kursor mouse hover. Gunakan untuk aksi netral yang tidak memerlukan perhatian tinggi. 'Batal', 'Tutup', 'Lewati Langkah Ini'.
20 Destructive / Danger Button Tombol peringatan berwarna merah terang (#EF4444) untuk aksi berisiko fatal. Wajib pasangkan dengan dialog konfirmasi sebelum eksekusi berjalan. 'Hapus Database', 'Batalkan Langganan'.
21 Icon Button Tombol kotak kompak hanya berisi simbol grafis (misal: tombol sampah, pensil, bookmark). Wajib sertakan atribut aria-label untuk aksesibilitas screen reader. Toolbar editor teks, tombol favorit di kartu produk.
22 Split / Dropdown Button Tombol terbelah dua (klik kiri = eksekusi cepat, klik panah kanan = daftar opsi). Ideal untuk fitur dengan satu aksi default populer dan beberapa alternatif. 'Publikasikan Sekarang' vs 'Jadwalkan Besok'.
23 Floating Action Bar (Bulk Bar) Bilah aksi melayang yang muncul saat beberapa baris data dalam tabel dipilih. Tampilkan jumlah item terpilih dan aksi massal (Hapus Semua, Export, Tandai Selesai). Aksi centang batch di Gmail atau dashboard admin.
24 Toggle Button Tombol yang mempertahankan status ditekan/aktif (stateful button). Gunakan aria-pressed="true/false" untuk mengabari screen reader status penekanan. Tombol Bold, Italic, Strikethrough di Word/Docs.
25 Copy-to-Clipboard Button Tombol penyalin teks/API key otomatis dengan perubahan ikon ke centang hijau. Ganti teks/ikon sementara selama 2 detik ke 'Tersalin!' agar pengguna yakin aksi berhasil. Salin kode cURL di dokumentasi developer API.

3. Kontrol Formulir & Input Teks (Form Controls)

Komponen penangkap input data teks, pilihan numerik, tanggal, dan berkas dari pengguna.

No Nama Komponen UI Definisi & Peran Fungsional UX Best Practice & Aksesibilitas (WCAG) Contoh Industri
26 Single-line Text Input Kotak isian teks dasar 1 baris untuk nama, email, atau username. Selalu sertakan label eksplisit di atas input dan placeholder deskriptif. Form pendaftaran nama akun pengguna.
27 Password Input with Eye Toggle Input kata sandi tersensor dengan ikon mata pengalih visibilitas teks. Bantu kurangi eror typo pengguna tanpa mengorbankan keamanan di tempat umum. Layar login semua aplikasi modern.
28 Textarea (Multi-line Input) Area isian teks luas dengan tinggi otomatis atau pegangan resize vertikal. Sertakan indikator penghitung sisa karakter (misal: 140/500 kata). Form ulasan produk, kotak pesan pengaduan.
29 Search Input with Clear Button Kolom pencarian dengan ikon kaca pembesar dan tombol 'x' pembersih teks instan. Pasangkan debounce timer (300ms) pada pemanggilan query API pencarian. Kolom pencarian e-commerce atau filter tabel.
30 Number Stepper Input Kotak angka dengan tombol plus dan minus (+ / -) untuk menambah kuantitas. Cegah angka menjadi negatif atau melebihi stok gudang yang tersedia. Jumlah kuantitas barang di keranjang belanja.
31 Select / Dropdown Menu Menu pemilih 1 opsi dari daftar tersembunyi yang hemat ruang vertikal. Gunakan untuk opsi antara 5 hingga 15 item; di bawah 5 item lebih baik Radio Button. Pilihan nama Provinsi atau opsi pengiriman.
32 Multi-Select Dropdown Dropdown yang memungkinkan memilih lebih dari satu opsi sekaligus berbentuk tag. Beri tombol 'Pilih Semua' dan 'Hapus Semua' jika opsinya panjang. Filter multi-kategori produk e-commerce.
33 Combobox / Autocomplete Input teks dengan pencarian dinamis yang menyaring ribuan opsi saat diketik. Tampilkan highlight tebal pada karakter huruf yang cocok dengan ketikan user. Pencarian kota bandara tiket pesawat (CGK, SUB, DPS).
34 Checkbox Kotak centang untuk pilihan majemuk mandiri atau grup multi-opsi. Teks label harus bisa diklik untuk mencentang kotak (bungkus dengan label for). Syarat & Ketentuan [x], filter fitur e-commerce.
35 Radio Button Lingkaran pemilih opsi tunggal mutlak yang saling meniadakan (mutually exclusive). Harus selalu ada 1 opsi default yang tercentang sejak awal layar dimuat. Pilihan Jenis Kelamin (Pria/Wanita), metode pembayaran.
36 Toggle Switch Saklar geser on/off instan untuk preferensi sistem tanpa butuh tombol simpan. Hanya gunakan untuk perubahan state langsung (misal: Nyalakan Wifi, Mode Gelap). Pengaturan privasi akun di menu Settings.
37 Range Slider Penggeser nilai batas numerik kontinu pada track garis horizontal. Tampilkan nilai angka yang sedang aktif tepat di atas pegangan geser (thumb). Pengatur volume suara atau kecerahan layar monitor.
38 Dual Handle Range Slider Slider dengan 2 titik pegangan untuk menentukan nilai rentang minimum dan maksimum. Cegah handle kiri melewati handle kanan agar nilai min tidak lebih besar dari max. Filter harga barang: Rp 100.000 s/d Rp 2.500.000.
39 Date Picker Kalender pop-up pemilih tanggal hari, bulan, dan tahun. Dukung input ketik manual via keyboard selain klik kalender visual. Input tanggal lahir atau tanggal reservasi.
40 Date Range Picker Kalender pemilih rentang dua tanggal (mulai s/d selesai). Beri warna sorotan lembut pada rentang hari yang berada di antara kedua tanggal. Pemesanan kamar hotel (Check-in & Check-out).
41 Time Picker Pemilih jam dan menit digital atau jam putar analog jarum jam. Tampilkan format 24 jam atau AM/PM yang konsisten dengan preferensi regional. Jadwal temu janji dokter atau reservasi restoran.
42 File Dropzone Area seret-lepas berkas dokumen atau foto dengan validasi format dan ukuran. Tampilkan daftar ekstensi yang didukung (.pdf, .png maks 5MB) dan progress upload. Unggah dokumen KYC KTP atau bukti transfer struk bank.
43 OTP / PIN Input Deretan 4-6 kotak kecil terpisah yang otomatis lompat fokus ke kotak selanjutnya. Dukung auto-paste clipboard satu klik dan fitur SMS auto-fill di mobile. Verifikasi kode login WhatsApp atau transaksi perbankan.

4. Kontrol Input Khusus & Lanjutan (Advanced Inputs)

Komponen input tingkat lanjut untuk penanganan media kaya, format data terstruktur, dan validasi khusus.

No Nama Komponen UI Definisi & Peran Fungsional UX Best Practice & Aksesibilitas (WCAG) Contoh Industri
44 Tag / Chip Input Kotak input yang otomatis mengubah kata berkoma menjadi lencana chip ber-tombol silang. Dukung penekanan tombol Backspace untuk menghapus chip terakhir saat input kosong. Input tag kata kunci artikel blog atau keahlian di LinkedIn.
45 Rich Text Editor (WYSIWYG) Kanvas editor teks berformat dengan toolbar tebal, miring, list, tabel, dan gambar. Pastikan hasil output kode HTML bersih (sanitized) untuk mencegah serangan XSS. Editor artikel Notion, WordPress Gutenberg, Medium.
46 Color Picker Pemilih palet warna visual dengan slider spektrum, eyedropper, dan input Hex/RGBA. Tampilkan swatch warna yang sering digunakan agar user tidak perlu mengetik hex berulang. Pengaturan warna tema Figma, Canva, panel kustomisasi web.
47 Star Rating Input Deretan 5 bintang interaktif untuk memberikan skor penilaian ulasan pelanggan. Dukung setengah bintang (half-star) untuk skor desimal yang lebih presisi. Rating ulasan produk Tokopedia, review film IMDb.
48 Signature Pad Kanvas sentuh untuk membubuhkan tanda tangan basah digital secara presisi. Sediakan tombol 'Hapus' dan tombol 'Unduh Tanda Tangan PNG Transparan'. Aplikasi kurir penerimaan paket, dokumen legal DocuSign.
49 Credit Card Input with Auto-formatting Input kartu kredit dengan spasi tiap 4 digit dan deteksi otomatis logo kartu. Gunakan algoritma Luhn Check untuk validasi keaslian nomor kartu di sisi client. Layar pembayaran Stripe Checkout, Midtrans.
50 Currency / Masked Input Input uang yang otomatis menyisipkan simbol mata uang dan titik pemisah ribuan. Cegah input huruf dan simpan nilai murni tanpa format ke database backend. Input harga produk atau nominal transfer rekening m-Banking.
51 Phone Input with Country Flag Input nomor handphone dengan dropdown bendera negara dan kode panggil (+62). Deteksi negara otomatis menggunakan GeoIP agar user tidak perlu mencari negaranya. Pendaftaran akun WhatsApp, Uber, Telegram.
52 Mention / User Tagging Input Input teks yang memunculkan dropdown rekomendasi profil saat mengetik simbol @. Navigasi daftar dropdown harus lancar menggunakan tombol panah keyboard. Komentar GitHub PR, mention di Slack atau Discord.
53 Captcha / Verification Widget Widget verifikasi keamanan interaktif untuk memastikan pengguna bukan bot otomatis. Gunakan Cloudflare Turnstile atau invisible reCAPTCHA v3 untuk meminimalkan friksi UX. Form pendaftaran akun atau reset kata sandi.

5. Umpan Balik, Status & Dialog (Feedback & Overlays)

Komponen pemberi sinyal status operasi, peringatan keselamatan, dan dialog konfirmasi aksi mendesak.

No Nama Komponen UI Definisi & Peran Fungsional UX Best Practice & Aksesibilitas (WCAG) Contoh Industri
54 Toast / Snackbar Notifikasi melayang non-blocking di sudut layar yang hilang otomatis dalam 3-5 detik. Berikan opsi tombol 'Undo' untuk aksi yang tidak sengaja tertekan pengguna. 'File berhasil diarsipkan (Undo)', 'Tautan tersalin'.
55 Alert Banner (Callout) Kotak status statis di dalam alur halaman (Info biru, Sukses hijau, Peringatan kuning, Eror merah). Tuliskan solusi pemecahan masalah dengan lugas, bukan sekadar pesan eror membingungkan. 'Email Anda belum diverifikasi. Kirim ulang link aktivasi'.
56 Modal Dialog Jendela pop-up blocking dengan backdrop gelap yang membekukan interaksi halaman dasar. Wajib terapkan focus trap (fokus keyboard terkurung di dalam modal) dan tombol ESC untuk tutup. Dialog tambah data baru, modal login pop-up.
57 Confirmation Dialog Modal khusus pertanyaan Ya/Tidak dengan tombol konfirmasi berwarna bahaya. Tuliskan dampak aksi secara eksplisit ('Data yang dihapus tidak dapat dipulihkan'). Konfirmasi hapus project di GitHub atau Vercel.
58 Off-canvas Drawer (Side Sheet) Panel yang meluncur masuk dari sisi kanan/kiri menutupi sebagian kanvas kerja. Sangat efektif untuk menampilkan detail data tanpa membawa user pindah halaman. Keranjang belanja kilat, panel inspeksi atribut Figma.
59 Bottom Sheet Panel geser dari dasar layar smartphone yang bisa digeser naik-turun dengan sentuhan jari. Gunakan untuk memilih opsi cepat pada pengalaman mobile-first. Menu bagikan (Share Sheet) iOS dan Android.
60 Tooltip Gelembung teks mikro penjelas saat kursor mouse hover pada ikon tanpa teks label. Hanya gunakan untuk informasi singkat pendukung; jangan simpan info krusial di tooltip. Penjelas fungsi ikon kuas atau pin di aplikasi.
61 Popover Gelembung melayang interaktif yang memuat form mini, filter, atau kartu profil saat diklik. Popover tetap terbuka saat diklik sampai pengguna mengklik area luar kanvas (click outside). Kartu preview profil user di GitHub saat hover avatar.
62 Determinate Progress Bar Bilah kemajuan dengan persentase angka pasti (0% s/d 100%). Tampilkan sisa waktu estimasi jika proses berlangsung lebih dari 5 detik. Progress unggah file dokumen 4.2 MB / 10 MB (42%).
63 Indeterminate Progress Bar Bilah animasi garis bergerak berulang untuk proses yang durasinya tidak terprediksi. Gunakan saat menunggu respons query basis data yang tidak memiliki status kemajuan bertahap. Bilah animasi di bagian atas saat halaman Next.js memuat rute baru.
64 Circular Spinner Loader Cincin berputar penanda aplikasi sedang sibuk memproses permintaan di latar belakang. Jangan gunakan spinner layar penuh jika hanya 1 tombol atau kartu kecil yang sedang memuat. Ikon loading di dalam tombol submit form.
65 Skeleton Screen Loader Kerangka berkilau abu-abu (shimmer) yang meniru bentuk fisik asli konten artikel/kartu. Jauh lebih disukai daripada spinner karena menurunkan persepsi waktu tunggu pengguna. Tampilan loading YouTube, Facebook, LinkedIn feed.

6. Penyajian Data & Kontainer Konten (Data Display)

Komponen perangkum informasi agar kumpulan data kompleks mudah dicerna secara cepat dan terstruktur.

No Nama Komponen UI Definisi & Peran Fungsional UX Best Practice & Aksesibilitas (WCAG) Contoh Industri
66 Bento Card Kartu modular berkedalaman visual tegas perangkum satu kesatuan informasi atau fitur. Beri hover elevasi halus (translateY -2px) dan border berpendar biru saat didekati kursor. Kartu showcase Apple, dashboard modern SaaS.
67 Data Table Tabel baris-kolom dengan sticky header, pagination, dan kemampuan sortir data. Ratakan angka ke kanan (right-align) dan teks ke kiri (left-align) untuk keterbacaan data. Daftar transaksi order penjualan, log audit server.
68 Data Grid (Spreadsheet-like) Tabel tingkat lanjut dengan kemampuan inline-editing langsung pada sel data dan freeze column. Sediakan shortcut keyboard untuk navigasi sel mirip Excel (Tab, Enter, Panah). Airtable, Google Sheets, ERP inventaris barang.
69 Badge / Status Pill Lencana oval kecil kontras penunjuk status real-time (Live, Sukses, Gagal, Baru). Gunakan warna semantik konsisten: Hijau (Sukses), Kuning (Pending), Merah (Gagal). Lencana status pembayaran 'Lunas' di faktur invoice.
70 Tag / Category Label Label penanda metadata, kategori produk, atau topik artikel. Dapat diklik untuk menyaring seluruh konten yang memiliki tag serupa. Tag 'React', 'PostgreSQL' di blog engineering.
71 Avatar Gambar foto profil pengguna bulat atau kotak dengan inisial cadangan jika gambar gagal dimuat. Wajib sertakan alt text berupa nama lengkap pemilik akun. Foto profil pengguna di sudut kanan atas navbar.
72 Avatar Group (Stack) Tumpukan foto profil bertingkat yang saling tumpang-tindih dengan counter penutup (+5). Beri border sekeliling avatar sewarna background agar tumpukan tampak rapi dan berjarak. Daftar kolaborator proyek di Figma atau Google Docs.
73 Accordion / Collapse Panel lipat vertikal untuk menghemat ruang kanvas dengan menyembunyikan detail sekunder. Beri ikon panah chevron rotasi 180 derajat saat panel dibuka. Halaman Tanya Jawab Populer (FAQ), spesifikasi barang.
74 Carousel / Image Slider Kontainer geser horizontal untuk menampilkan galeri foto atau banner promo bergiliran. Berikan tombol jeda (Pause) jika slider berjalan otomatis (Auto-play) demi aksesibilitas. Banner promo beranda Shopee, galeri foto properti Airbnb.
75 Timeline / Event Stream Garis riwayat vertikal kronologis kejadian dengan titik simpul status. Urutkan kejadian terbaru di paling atas dan tandai titik kejadian terakhir dengan warna cerah. Pelacakan resi pengiriman kurir JNE, riwayat audit git commit.
76 Empty State Tampilan ilustratif ramah saat tabel, keranjang, atau kotak masuk belum memiliki data sama sekali. Sertakan tombol Call-to-Action langsung (misal: 'Mulai Belanja', 'Buat Dokumen Pertama'). Layar kotak masuk pesan saat masih kosong.
77 Error State / 404 Visual Tampilan visual saat rute halaman tidak ditemukan atau sambungan internet offline. Sediakan tombol 'Coba Lagi' atau tautan 'Kembali ke Beranda' yang jelas. Halaman 404 Not Found ramah pengguna.
78 Metric KPI Stat Card Kartu statistik angka besar dengan lencana persentase tren naik/turun hijau atau merah. Tampilkan konteks perbandingan (misal: '+14% dibandingkan bulan lalu'). Kartu Total Revenue, Active Users di Google Analytics.
79 Key-Value Description List Daftar pasangan label dan nilai terstruktur rapi dua kolom. Gunakan tag HTML semantik dl, dt, dan dd untuk pembacaan akurat oleh screen reader. Rincian spesifikasi mesin laptop (RAM, Processor, Storage).
80 Activity Feed Stream Aliran linier kartu aktivitas pengguna waktu nyata (mirip timeline linimasa). Kelompokkan aktivitas berdasarkan hari (Hari Ini, Kemarin, Minggu Lalu). Linimasa aktivitas tim di Jira, GitHub feed.

7. Media, Grafis & Visualisasi (Media & Visualization)

Komponen pemutar berkas multimedia, penampil visual resolusi tinggi, dan visualisasi grafik data.

No Nama Komponen UI Definisi & Peran Fungsional UX Best Practice & Aksesibilitas (WCAG) Contoh Industri
81 Lightbox / Image Modal Penampil foto layar penuh berlatar gelap saat thumbnail gambar diklik. Sediakan kontrol zoom, tombol panah foto berikutnya, dan tombol keyboard ESC untuk keluar. Galeri foto portofolio, tampilan foto produk e-commerce.
82 Custom Video Player Bar Bilah kontrol video kustom (Play/Pause, Timeline Scrubber, Volume, Closed Caption, Fullscreen). Sertakan dukungan shortcut spasi untuk Play/Pause dan panah kanan/kiri untuk skip 5 detik. Pemutar video Netflix, YouTube, Vimeo.

3. CSS Grid vs Flexbox: Panduan Keputusan Arsitektur

Salah satu kesalahan paling mendasar frontend engineer adalah memaksakan Flexbox untuk mengatur seluruh halaman, atau menggunakan Grid untuk hal-hal sepele. Berikut adalah aturan baku industri:

Contoh Visual Nyata: CSS Flexbox (1D) vs CSS Grid (2D)
Render Langsung
Flexbox 1-Dimensi (Main Axis: space-between)
Velora App

Elemen fleksibel menyejajarkan diri secara horizontal pada satu baris.

CSS Grid 2-Dimensi (Bento Matrix: 2 Kolom x 2 Baris)
Item A (1x1)
Item B (1x1)
Item C (Span 2 Kolom Penuh)

Elemen C melintasi 2 kolom sekaligus membentuk struktur Bento.

Parameter CSS Flexbox (1-Dimensi) CSS Grid (2-Dimensi)
Dimensi Kerja Hanya satu sumbu dalam satu waktu: Baris (horizontal) ATAU Kolom (vertikal). Dua sumbu sekaligus: Mengontrol baris DAN kolom secara presisi bersamaan.
Pendekatan Desain Content-First: Elemen menentukan ukurannya sendiri, lalu Flexbox merapikan posisinya. Layout-First: Kerangka grid ditentukan terlebih dahulu, lalu elemen ditempatkan ke dalam sel yang tersedia.
Kasus Penggunaan Ideal
  • Navbar item (Logo di kiri, Menu di tengah, Profil di kanan).
  • Tombol dengan ikon di samping teks (`gap: 8px`).
  • Penyelarasan vertikal elemen (`align-items: center`).
  • Katalog produk e-commerce (`grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`).
  • Bento Grid Dashboard modern.
  • Layout utama halaman (Sidebar + Main Content + Header).
modern-layout.css — Standar Bento Grid Auto-Responsive 
/* 1. CSS Grid untuk Katalog / Bento Grid Responsif */
.bento-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 1.5rem; /* 24px via 8pt grid token */
}

/* 2. Flexbox untuk Komponen Mikro di dalam Kartu */
.bento-card-header {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 0.75rem; /* 12px */
}

  • Sticky vs Fixed: Gunakan position: sticky; top: 0; z-index: 1000; agar header tetap terlihat saat scroll tanpa menutupi konten di bawahnya saat load awal.

  • Mobile Hamburger: Pada layar <768px, menu horizontal disembunyikan dan dialihkan ke drawer overlay.

Area Above-the-Fold yang pertama kali dirender browser. Anatomi wajib Hero:

A. Saat ingin menyejajarkan ikon di sebelah teks tombol
B. Saat membangun struktur 2-dimensi yang mengontrol baris dan kolom secara serentak seperti katalog produk atau dashboard Bento Grid

A. Menjaga keterbacaan teks dan kenyamanan motorik mata agar pengguna tidak perlu menolehkan kepala dari ujung kiri ke ujung kanan monitor ultrawide
B. Karena browser akan mengalami crash jika merender lebih dari 1920 piksel
C. Untuk menghemat konsumsi kuota data internet
