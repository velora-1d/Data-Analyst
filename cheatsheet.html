1. Git Plumbing Commands (Internal Object Engine)
Tingkat Rendah
git hash-object -w --stdin Plumbing
Fungsi Internal: Membaca konten teks/biner dari stdin, menghitung checksum SHA-1 40-karakter, mengompresi payload via algoritma zlib Deflate, lalu langsung menulisnya ke .git/objects/xx/yyy sebagai objek Blob.
Kasus Nyata Produksi Menyimpan snapshot konfigurasi secara programatis atau memverifikasi integritas hash file tanpa perlu menyentuh staging area.
Pelajari di Modul 25
git cat-file -p <SHA> Plumbing
Fungsi Internal: Mendekompresi objek dari direktori objek Git dan mencetaknya dalam format yang mudah dibaca manusia (pretty-print). Gunakan flag -t untuk melihat tipe objeknya (blob, tree, commit, tag).
Kasus Nyata Produksi Memeriksa isi snapshot commit lama atau melihat referensi pointer Tree internal saat menelusuri bug korupsi repository.
Pelajari di Modul 14
git write-tree Plumbing
Fungsi Internal: Membekukan seluruh struktur file dan subfolder yang saat ini berada di staging index (.git/index) menjadi Tree Object biner, mengembalikan SHA-1 pohon direktori tersebut.
Kasus Nyata Produksi Membuat commit manual atau menyusun snapshot branch dalam script otomatisasi CI/CD bot tanpa campur tangan terminal manusia.
Pelajari di Modul 25
git commit-tree <TREE> -p <PARENT> -m "pesan" Plumbing
Fungsi Internal: Merangkai metadata commit (pohon tree, author, committer, timestamp UTC, parent commit hash, dan pesan) menjadi objek commit resmi tanpa perlu perintah git commit.
Kasus Nyata Produksi Membuat commit sintetis, menggabungkan riwayat merge khusus, atau membangun sistem integrasi versi kustom.
Pelajari di Modul 25
git update-ref refs/heads/main <SHA> Plumbing
Fungsi Internal: Memperbarui file referensi pointer branch secara atomik aman (thread-safe lock) ke commit SHA yang baru dibuat.
Kasus Nyata Produksi Memindahkan pointer branch ke commit baru tanpa mengubah status direktori kerja (working tree) Anda.
Pelajari di Modul 25
git verify-pack -v .git/objects/pack/*.idx Plumbing
Fungsi Internal: Mengurai indeks Packfiles Git untuk melihat daftar seluruh objek yang terkompresi, ukuran mentah, ukuran setelah kompresi delta, dan rantai turunan objek.
Kasus Nyata Produksi Mendiagnosa penyebab repository membengkak menjadi puluhan gigabyte dan menemukan objek file raksasa tersembunyi.
Pelajari di Modul 25
2. Git Forensik & Pemulihan Data (Disaster Recovery)
Emergency
git reflog Forensik
Fungsi Internal: Membaca catatan riwayat pergerakan pointer HEAD lokal. Setiap operasi checkout, commit, reset, rebase, atau merge dicatat beserta commit SHA asalnya, bahkan jika commit tersebut sudah tidak punya branch.
Kasus Nyata Produksi Menyelamatkan pekerjaan developer yang panik karena tidak sengaja menjalankan git reset --hard atau salah rebase.
Pelajari di Modul 25
git filter-repo --invert-paths --path <file> Maintenance
Fungsi Internal: Menulis ulang seluruh riwayat DAG repository dengan membuang objek file tertentu secara tuntas dari seluruh commit masa lalu, lalu memperbarui pointer parent dan tag secara konsisten.
Kasus Nyata Produksi Membersihkan API key, file .env berharga, atau database dump 2GB yang tidak sengaja terdorong ke GitHub publik.
Pelajari di Modul 25
git bisect start / bad / good Diagnostik
Fungsi Internal: Menggunakan algoritma pencarian biner (binary search O(log N)) pada riwayat commit untuk melacak commit tepat mana yang pertama kali memperkenalkan regresi bug ke dalam sistem.
Kasus Nyata Produksi Menemukan akar penyebab fitur login rusak di antara ratusan commit merge dari 20 engineer selama sprint berlangsung.
Pelajari di Modul 25
3. Diagnostik Jaringan & Sockets Linux
Networking
ss -tulnp Network
Fungsi Internal: Mengambil status socket langsung dari subsistem netlink Linux kernel secara instan (jauh lebih cepat dibanding netstat) untuk menampilkan semua port TCP/UDP yang sedang LISTEN beserta Process ID (PID)-nya.
Kasus Nyata Produksi Menemukan proses mana yang menyandera port 80/443 saat web server gagal start karena pesan error Address already in use.
Pelajari di Modul 17
ip -br a && ip route Network
Fungsi Internal: Menginspeksi interface kartu jaringan fisik/virtual (eth0, lo, veth Docker, flannel.1 K8s), memeriksa netmask CIDR (/24, /16), serta memeriksa tabel routing default gateway kernel.
Kasus Nyata Produksi Memverifikasi IP subnetting server privat VPC dan memastikan paket data tidak tersesat karena kesalahan default gateway.
Pelajari di Modul 17
sudo tcpdump -nn -i any port 80 -c 20 Sniffer
Fungsi Internal: Mengaitkan kernel filter libpcap pada driver antarmuka jaringan untuk menyadap paket raw frame secara nyata, menampilkan flag TCP ([S] SYN, [.] ACK, [P] PUSH, [F] FIN).
Kasus Nyata Produksi Membuktikan apakah firewall cloud memblokir paket SYN atau apakah backend merespons dengan paket TCP Reset (RST).
Pelajari di Modul 17
curl -w "DNS: %{time_namelookup}s | Connect: %{time_connect}s | TTFB: %{time_starttransfer}s | Total: %{time_total}s\n" -so /dev/null <URL> Performa
Fungsi Internal: Memanfaatkan instrumentasi internal libcurl untuk mengukur latensi milidetik di setiap etape: DNS lookup, TCP 3-Way Handshake, negosiasi TLS, hingga respon byte pertama (TTFB).
Kasus Nyata Produksi Mengetahui letak bottleneck request lambat: apakah di lambatnya DNS resolver, delay handshake TCP, atau query database lambat di backend.
Pelajari di Modul 10
4. Manajemen Proses, Syscall & Batas Kernel
Linux Kernel
sudo lsof -p <PID> | wc -l Diagnostik
Fungsi Internal: Memindai tabel file descriptor (FD) milik suatu proses di virtual filesystem /proc/<PID>/fd untuk menghitung jumlah file, koneksi socket TCP, dan pipe yang sedang dibuka.
Kasus Nyata Produksi Mendiagnosa socket leak pada aplikasi Node.js atau Go yang menyebabkan crash fatal EMFILE: Too many open files.
Pelajari di Modul 18
sudo strace -p <PID> -f -e trace=network,file Syscall
Fungsi Internal: Menggunakan interface debugger kernel ptrace untuk menyadap setiap system call (seperti epoll_wait, read, write, openat) yang dibuat aplikasi ke kernel.
Kasus Nyata Produksi Mengungkap mengapa sebuah proses menggantung (hang 100% CPU): apakah sedang mentok di lock file atau menunggu balasan socket.
Pelajari di Modul 18
ulimit -n 65535 Sistem
Fungsi Internal: Mengubah batas kuota Resource Limit (soft limit & hard limit) jumlah File Descriptor per shell session. Standar bawaan Linux biasanya 1024 yang sangat kecil untuk server dengan 10.000 koneksi bersamaan.
Kasus Nyata Produksi Meningkatkan kapasitas server Nginx/Redis agar sanggup menampung 65.000 koneksi konkurensi tinggi tanpa memuntahkan error socket limit.
Pelajari di Modul 18
5. Web Server, Nginx & Systemd Services
Web Server
sudo nginx -t Nginx
Fungsi Internal: Membaca dan mem-parsing seluruh file konfigurasi di /etc/nginx/nginx.conf dan sub-konfigurasi virtual host tanpa memengaruhi proses master/worker yang sedang melayani pengunjung.
Kasus Nyata Produksi Golden Rule SRE: Selalu jalankan nginx -t sebelum reload agar kesalahan titik-koma (syntax error) tidak menjatuhkan server produksi.
Pelajari di Modul 19
sudo nginx -s reload Nginx
Fungsi Internal: Mengirimkan sinyal POSIX SIGHUP ke proses Nginx Master. Master membaca konfigurasi baru, menyalakan worker baru, dan mematikan worker lama secara elegan (graceful) setelah koneksi aktifnya selesai.
Kasus Nyata Produksi Memperbarui sertifikat SSL Let's Encrypt atau mengubah upstream proxy tanpa ada 1 pun pengguna yang mengalami kegagalan koneksi (zero downtime).
Pelajari di Modul 19
journalctl -u nginx -f -n 50 Systemd
Fungsi Internal: Melakukan streaming biner log sistem dari daemon systemd-journald khusus untuk unit service tertentu secara live (follow flag -f).
Kasus Nyata Produksi Memantau log proses startup backend API untuk mengetahui penyebab crash instan saat service baru saja di-deploy.
Pelajari di Modul 19
6. Kontainer, Docker & Kubernetes Orchestration
Cloud Native
sudo unshare --pid --net --mount --fork /bin/bash Kernel
Fungsi Internal: Memanggil syscall unshare() Linux Kernel untuk melepaskan proses dari namespace host. Proses di dalamnya melihat PID 1 miliknya sendiri dan stack network tersendiri murni tanpa Docker daemon.
Kasus Nyata Produksi Fondasi inti bagaimana kontainer dibuat: membuktikan bahwa kontainer bukanlah Virtual Machine, melainkan proses Linux biasa yang dibatasi namespace.
Pelajari di Modul 20
docker run --memory="512m" --pids-limit 100 -d myapp Docker
Fungsi Internal: Menginstruksikan kernel cgroups v2 (/sys/fs/cgroup/) untuk menetapkan kuota hard RAM 512MB dan mencegah proses membuat child process lebih dari 100 thread.
Kasus Nyata Produksi Mencegah satu aplikasi yang bocor memori menenggelamkan seluruh node server produksi (OOM killer containment).
Pelajari di Modul 20
kubectl rollout status deployment/web-api --timeout=60s Kubernetes
Fungsi Internal: Memantau siklus rolling update Kubernetes. Mengonfirmasi bahwa Pod generasi baru telah lolos uji readinessProbe sebelum mematikan Pod versi sebelumnya.
Kasus Nyata Produksi Kunci dalam pipeline CI/CD otomatis: membatalkan deployment dan melakukan auto-rollback jika Pod baru mengalami crash loop.
Pelajari di Modul 21
7. Diagnostik Mobile, Android ADB & iOS Simulator
Mobile CLI
adb logcat *:E --buffer=crash Android
Fungsi Internal: Melakukan streaming biner log sistem Android OS dari daemon ADB, difilter khusus untuk menangkap pesan error fatal (Fatal Exception), NullPointer, dan Native SIGSEGV crash.
Kasus Nyata Produksi Mengungkap stacktrace crash aplikasi Android saat diuji di HP fisik tanpa IDE Android Studio terbuka.
Pelajari di Modul 31
xcrun simctl push booted <bundle.id> payload.json iOS
Fungsi Internal: Mengirimkan simulasi payload notifikasi APNs langsung ke simulator iPhone yang sedang aktif (booted) tanpa membutuhkan sertifikat Apple Developer berbayar.
Kasus Nyata Produksi Menguji penanganan Push Notification di aplikasi iOS dan memverifikasi deep link navigation saat notifikasi diklik.
Pelajari di Modul 32
flutter run --profile Flutter
Fungsi Internal: Mengompilasi aplikasi Flutter dengan optimasi AOT penuh mendekati mode rilis, namun tetap mempertahankan instrumentasi Dart DevTools Timeline untuk mengukur performa rendering GPU Impeller per frame.
Kasus Nyata Produksi Mendiagnosa frame drop pada layar daftar produk panjang untuk memastikan widget UI berjalan stabil di 60-120 FPS.
