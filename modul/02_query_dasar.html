Query Dasar & Pemfilteran Data E-Commerce

Pelajari cara mengambil, memfilter transaksi, mencari produk, mengurutkan data omzet tertinggi, dan membatasi baris data transaksi di toko online menggunakan klausa SQL fundamental.

45 menit Fundamental Pemula Database: E-Commerce Indonesia sql/02_query_dasar.sql

1. Anatomi & Urutan Eksekusi Query SQL

Banyak pemula mengira SQL dieksekusi dari baris pertama (SELECT). Padahal database engine mengeksekusi klausa dengan urutan yang berbeda:

Urutan Tulis (Syntax)Urutan Eksekusi EngineTindakan yang Dilakukan
1. SELECT3. WHEREDatabase membaca tabel di FROM dulu, lalu memfilter baris di WHERE
2. FROM1. FROMMenentukan tabel sumber data utama
3. WHERE2. JOIN / ONMenggabungkan relasi tabel sebelum dievaluasi
4. ORDER BY4. SELECTMemilih kolom dan menghitung kolom kalkulasi
5. LIMIT5. ORDER BY & LIMITMengurutkan baris akhir dan memotong jumlah data

2. SELECT, Alias, & Kolom Kalkulasi

Hindari kebiasaan menggunakan SELECT * pada production database karena membebani memori. Pilihlah kolom yang spesifik dan gunakan AS untuk memberi nama alias yang mudah dipahami stakeholder bisnis.

SQL Query
-- Mengambil katalog produk dengan kolom kalkulasi dan alias
SELECT 
    produk_id,
    nama_produk              AS nama_barang,
    berat_gram,
    berat_gram / 1000.0       AS berat_kg
FROM produk
LIMIT 5;

3. WHERE & Operator Perbandingan

Klausa WHERE menyaring baris berdasarkan kondisi logika (True/False). Operator yang didukung: =, != (atau <>), >, <, >=, <=.

SQL Query
-- Menampilkan transaksi pesanan yang telah 'Selesai' dengan nilai di atas Rp 300.000
SELECT 
    nomor_invoice,
    pelanggan_id,
    status_pesanan,
    total_bayar
FROM pesanan
WHERE status_pesanan = 'Selesai'
  AND total_bayar >= 300000
LIMIT 5;

4. Logika AND, OR, dan NOT

Operator logika menggabungkan multi-kondisi. Selalu gunakan kurung buka dan tutup ( ... ) jika menggabungkan AND dan OR untuk menghindari kesalahan urutan evaluasi boolean.

SQL Query
-- Pesanan yang selesai ATAU dikirim, dan memiliki ongkir > 15000
SELECT 
    nomor_invoice,
    status_pesanan,
    ongkos_kirim,
    total_bayar
FROM pesanan
WHERE (status_pesanan = 'Selesai' OR status_pesanan = 'Dikirim')
  AND ongkos_kirim > 15000
LIMIT 5;

5. ORDER BY, LIMIT, dan OFFSET (Paginasi Data)

ORDER BY kolom DESC mengurutkan dari nilai terbesar ke terkecil. Dikombinasikan dengan LIMIT n OFFSET m, kita dapat membuat paginasi tabel data aplikasi.

SQL Query
-- Top 5 Transaksi dengan Belanja Terbesar
SELECT 
    nomor_invoice,
    pelanggan_id,
    tanggal_pesanan,
    total_bayar
FROM pesanan
ORDER BY total_bayar DESC
LIMIT 5;

-- Paginasi: Halaman ke-2 (lewati 5 baris pertama, ambil 5 berikutnya)
SELECT nomor_invoice, total_bayar 
FROM pesanan 
ORDER BY total_bayar DESC 
LIMIT 5 OFFSET 5;

6. DISTINCT: Menghapus Duplikasi Baris

SQL Query
-- Melihat daftar kota dan provinsi unik asal pelanggan
SELECT DISTINCT 
    provinsi,
    kota
FROM alamat_pelanggan
ORDER BY provinsi, kota;

7. BETWEEN: Rentang Angka & Tanggal

SQL Query
-- Pesanan yang terjadi sepanjang Kuartal 3 (Juli - September 2023)
SELECT 
    nomor_invoice,
    tanggal_pesanan,
    total_bayar
FROM pesanan
WHERE tanggal_pesanan BETWEEN '2023-07-01' AND '2023-09-30 23:59:59'
ORDER BY tanggal_pesanan
LIMIT 5;

8. Operator IN & NOT IN

SQL Query
-- Pelanggan yang beralamat di kota metropolitan utama
SELECT pelanggan_id, label_alamat, kota, provinsi
FROM alamat_pelanggan
WHERE kota IN ('Jakarta Selatan', 'Surabaya', 'Bandung', 'Medan')
LIMIT 6;

9. LIKE & Pencarian Pola Teks

SQL Query
-- Mencari produk yang mengandung kata 'Kaos' atau 'Kemeja'
SELECT produk_id, nama_produk, deskripsi
FROM produk
WHERE nama_produk LIKE '%Kaos%' 
   OR nama_produk LIKE '%Kemeja%';
