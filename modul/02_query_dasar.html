Query Dasar & Pemfilteran Data E-Commerce

Pelajari cara mengambil, memfilter transaksi, mencari produk, mengurutkan data omzet tertinggi, dan membatasi baris data transaksi di toko online menggunakan klausa SQL fundamental.

Fondasi Konsep: Apa Sebenarnya Query SQL Itu?
Ibarat Menyuruh Pelayan Mengambil Barang di Gudang
Apa Ini Sebenarnya?

Query adalah surat perintah atau pertanyaan sopan yang kita ajukan kepada database. Alih-alih membongkar seluruh isi lemari, kita hanya meminta lembaran data tertentu yang kita inginkan.

Masalah Nyata Apa yang Diselesaikan?

Jika toko online memiliki 1 juta barang, kasir tidak mungkin mencetak 1 juta lembar kertas sekaligus karena layar komputer akan macet total. Kasir hanya butuh melihat 20 produk per halaman (Paginasi).

Analogi Kehidupan Sehari-Hari

Ibarat Anda menyuruh pelayan gudang: "Tolong ambilkan saya (SELECT) dari lemari minuman (FROM) yang harganya di bawah 20 ribu (WHERE), urutkan dari yang termurah (ORDER BY), dan bawa 10 botol saja (LIMIT)!"

Kapan Kita Memakainya?

Dipakai setiap detik dalam hidup aplikasi modern: saat pembeli mencari barang di kotak pencarian Shopee/Tokopedia, melihat daftar transaksi kemarin, atau memfilter barang promo diskon.

1. Anatomi & Urutan Eksekusi Query SQL

Banyak pemula mengira SQL dieksekusi dari baris pertama (SELECT). Padahal database engine mengeksekusi klausa dengan urutan yang berbeda:

Urutan Tulis (Syntax)Urutan Eksekusi EngineTindakan yang Dilakukan
1. SELECT3. WHEREDatabase membaca tabel di FROM dulu, lalu memfilter baris di WHERE
2. FROM1. FROMMenentukan tabel sumber data utama
3. WHERE2. JOIN / ONMenggabungkan relasi tabel sebelum dievaluasi
4. ORDER BY4. SELECTMemilih kolom dan menghitung kolom kalkulasi
5. LIMIT5. ORDER BY & LIMITMengurutkan baris akhir dan memotong jumlah data

2. SELECT, Kata Kunci AS (Aliasing), & Kolom Kalkulasi

Hindari kebiasaan menggunakan SELECT * pada production database karena membebani memori server dan bandwidth jaringan. Pilihlah kolom spesifik yang dibutuhkan, dan gunakan kata kunci AS (Aliasing) untuk memberi nama samaran yang jelas dan ramah bagi stakeholder bisnis.

Apa Itu Kata Kunci AS & Mengapa Wajib Dipahami?

Kata kunci AS digunakan untuk membuat Alias (Nama Samaran Sementara) pada sebuah kolom atau tabel selama query berlangsung. Nama asli di tabel database sama sekali tidak berubah.

3 Skenario Utama Penggunaan AS

Skenario PenggunaanMengapa Dibutuhkan?Contoh Penulisan
1. Merapikan Header Kolom Laporan Mengubah nama kolom database teknis/singkat menjadi istilah bisnis yang langsung siap ditampilkan di dashboard BI / Excel. SELECT tgl_psn AS tanggal_transaksi
2. Menamai Kolom Hasil Kalkulasi Ekspresi matematika seperti perkalian/pengurangan tidak punya nama kolom bawaan. Tanpa AS, header laporan akan jelek (misal bertuliskan harga * 0.1). SELECT harga * 0.11 AS ppn_rupiah
3. Table Alias (Mempersingkat Tabel) Mempersingkat penulisan nama tabel panjang saat melakukan JOIN relasi antar-tabel serta mencegah ambiguitas nama kolom. FROM riwayat_transaksi_pelanggan AS rtp

Aturan Penulisan Nama Alias di SQL

  • Satu Kata (Direkomendasikan): Ditulis langsung tanpa spasi, menggunakan format snake_case. Contoh: AS total_omzet.
  • Mengandung Spasi / Karakter Khusus: Wajib dibungkus dengan tanda petik ganda (") atau kurung siku [ ]. Contoh: AS "Total Omzet (Rp)" atau AS [Laba Kotor]. Jangan gunakan tanda petik tunggal (') karena petik tunggal adalah standar untuk nilai teks/string literal!
  • Apakah kata AS opsional? Ya, di sebagian besar SQL, menulis SELECT nama_produk nama diperbolehkan. Namun SANGAT DIREKOMENDASIKAN selalu menulis AS secara eksplisit. Jika Anda lupa tanda koma , antara dua kolom (misal: SELECT nama harga FROM produk), SQL akan mengira kolom harga adalah alias dari nama!
SQL Query: Penerapan Lengkap Kata Kunci AS
-- Mengambil katalog produk dengan kolom kalkulasi dan alias AS
SELECT 
    produk_id,
    -- 1. Merapikan nama kolom teknis
    nama_produk              AS nama_barang,
    berat_gram,
    -- 2. Menamai hasil kalkulasi pembagian desimal
    berat_gram / 1000.0       AS berat_kg,
    -- 3. Alias dengan spasi rapi untuk konsumsi eksekutif
    berat_gram / 1000.0       AS "Berat Paket (Kg)"
FROM produk AS p             -- 4. Table Alias (disingkat menjadi 'p')
LIMIT 5;
Jebakan Fatal: Bisakah Alias Kolom Dipakai di Klausa WHERE?

TIDAK BISA! Di dalam arsitektur database SQL, klausa WHERE dieksekusi sebelum klausa SELECT. Saat WHERE menyaring baris, nama alias tersebut belum dibuat oleh engine database.
- ❌ Salah: WHERE berat_kg > 2.0 (Error: no such column: berat_kg)
- ✔️ Benar: WHERE (berat_gram / 1000.0) > 2.0
Catatan: Kolom alias BISA digunakan di klausa ORDER BY karena ORDER BY dieksekusi setelah SELECT!

3. WHERE & Operator Perbandingan

Klausa WHERE menyaring baris berdasarkan kondisi logika (True/False). Operator yang didukung: =, != (atau <>), >, <, >=, <=.

Skenario Bisnis: Menyaring High-Value Customers

Tim Keuangan hanya memproses laporan invoice transaksi yang statusnya sudah 'Selesai' dan bernilai belanja tinggi (di atas Rp 300.000). Klausa WHERE menyeleksi baris mentah sebelum dikirimkan ke aplikasi.

SQL Query
-- Menampilkan transaksi pesanan yang telah 'Selesai' dengan nilai di atas Rp 300.000
SELECT 
    nomor_invoice,
    pelanggan_id,
    status_pesanan,
    total_bayar
FROM pesanan
WHERE status_pesanan = 'Selesai'
  AND total_bayar >= 300000
LIMIT 5;

4. Logika AND, OR, dan NOT

Operator logika menggabungkan multi-kondisi. Selalu gunakan kurung buka dan tutup ( ... ) jika menggabungkan AND dan OR untuk menghindari kesalahan urutan evaluasi boolean.

Aturan Penggunaan Tanda Kurung Logika Boolean

Di SQL, operator AND diproses lebih dulu daripada OR (operator precedence). Dengan memberi tanda kurung (status_pesanan = 'Selesai' OR status_pesanan = 'Dikirim'), Anda memastikan bahwa pengelompokan status dievaluasi sebagai satu kesatuan sebelum disaring dengan syarat ongkos_kirim > 15000.

SQL Query
-- Pesanan yang selesai ATAU dikirim, dan memiliki ongkir > 15000
SELECT 
    nomor_invoice,
    status_pesanan,
    ongkos_kirim,
    total_bayar
FROM pesanan
WHERE (status_pesanan = 'Selesai' OR status_pesanan = 'Dikirim')
  AND ongkos_kirim > 15000
LIMIT 5;

5. ORDER BY, LIMIT, dan OFFSET (Paginasi Data)

Buat Apa ORDER BY, LIMIT, & OFFSET Digunakan?
  • ORDER BY total_bayar DESC: Digunakan saat pimpinan bisnis ingin melihat leaderboard transaksi bernilai fantastis (Top Spender).
  • LIMIT 5 OFFSET 5: Merupakan fondasi arsitektur Paginasi Halaman (Page 1, Page 2) pada antarmuka web/mobile e-commerce agar aplikasi tidak memuat ribuan data sekaligus.
SQL Query
-- Top 5 Transaksi dengan Belanja Terbesar
SELECT 
    nomor_invoice,
    pelanggan_id,
    tanggal_pesanan,
    total_bayar
FROM pesanan
ORDER BY total_bayar DESC
LIMIT 5;

-- Paginasi: Halaman ke-2 (lewati 5 baris pertama, ambil 5 berikutnya)
SELECT nomor_invoice, total_bayar 
FROM pesanan 
ORDER BY total_bayar DESC 
LIMIT 5 OFFSET 5;

6. DISTINCT: Menghapus Duplikasi Baris

Fungsi & Kegunaan DISTINCT

Tabel alamat_pelanggan memiliki ribuan baris dengan nama kota yang berulang. SELECT DISTINCT provinsi, kota secara otomatis mengeliminasi nama kota yang sama sehingga memberikan daftar lokasi unik pelanggan untuk kebutuhan perencanaan ekspansi gudang logistik.

SQL Query
-- Melihat daftar kota dan provinsi unik asal pelanggan
SELECT DISTINCT 
    provinsi,
    kota
FROM alamat_pelanggan
ORDER BY provinsi, kota;

7. BETWEEN: Rentang Angka & Tanggal

Buat Apa Klausa BETWEEN Digunakan?

BETWEEN A AND B menyederhanakan penulisan kondisi rentang tertutup (tanggal >= A AND tanggal <= B). Sangat efektif untuk pembuatan laporan pendapatan bulanan atau kuartalan (Q1, Q2, Q3, Q4).

SQL Query
-- Pesanan yang terjadi sepanjang Kuartal 3 (Juli - September 2023)
SELECT 
    nomor_invoice,
    tanggal_pesanan,
    total_bayar
FROM pesanan
WHERE tanggal_pesanan BETWEEN '2023-07-01' AND '2023-09-30 23:59:59'
ORDER BY tanggal_pesanan
LIMIT 5;

8. Operator IN & NOT IN

SQL Query
-- Pelanggan yang beralamat di kota metropolitan utama
SELECT pelanggan_id, label_alamat, kota, provinsi
FROM alamat_pelanggan
WHERE kota IN ('Jakarta Selatan', 'Surabaya', 'Bandung', 'Medan')
LIMIT 6;

9. LIKE & Pencarian Pola Teks

SQL Query
-- Mencari produk yang mengandung kata 'Kaos' atau 'Kemeja'
SELECT produk_id, nama_produk, deskripsi
FROM produk
WHERE nama_produk LIKE '%Kaos%' 
   OR nama_produk LIKE '%Kemeja%';
