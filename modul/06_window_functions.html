Window Functions & Analisis Tren E-Commerce

Window Function adalah fitur andalan praktisi pengolahan data modern. Berbeda dengan GROUP BY yang menyusutkan baris, Window Function mempertahankan setiap baris transaksi asli sambil menghitung peringkat (ranking), pertumbuhan bulanan (MoM), dan total berjalan (Running Total).

2. ROW_NUMBER, RANK, dan DENSE_RANK

Buat Apa Fungsi Perankingan (Ranking) Digunakan?

Fungsi perankingan memungkinkan Anda memberikan peringkat pada baris data tanpa harus menciutkan tabel (berbeda dari GROUP BY):

  • ROW_NUMBER(): Memberikan penomoran unik mutlak (1, 2, 3, 4) cocok untuk penomoran baris.
  • DENSE_RANK(): Memberikan peringkat berdampingan tanpa melompati angka (1, 2, 2, 3) jika ada nilai belanja yang persis sama.
SQL Query
-- Perbandingan perankingan invoice pesanan
SELECT 
    nomor_invoice,
    total_bayar,
    ROW_NUMBER() OVER (ORDER BY total_bayar DESC) AS nomor_urut,
    RANK()       OVER (ORDER BY total_bayar DESC) AS ranking_gap,
    DENSE_RANK() OVER (ORDER BY total_bayar DESC) AS ranking_dense
FROM pesanan
WHERE status_pesanan = 'Selesai'
LIMIT 6;

3. PARTITION BY: Top 2 Produk Terlaris per Kategori

Skenario Bisnis: Top N Item per Kelompok

Direktur Merchandise ingin menampilkan "2 Produk Paling Laris" di masing-masing kategori barang. Klausa PARTITION BY k.kategori_id memecah jendela kalkulasi per kategori, lalu DENSE_RANK() meranking penjualan di dalam tiap kelompok kategori tersebut.

SQL Query
-- Top 2 Produk terlaris di setiap kategori produk
WITH CategoryProductSales AS (
    SELECT 
        k.nama_kategori,
        pr.nama_produk,
        SUM(rp.jumlah) AS total_terjual,
        DENSE_RANK() OVER (
            PARTITION BY k.kategori_id 
            ORDER BY SUM(rp.jumlah) DESC
        ) AS ranking_kategori
    FROM rincian_pesanan rp
    JOIN variasi_produk vp ON rp.variasi_id = vp.variasi_id
    JOIN produk pr         ON vp.produk_id = pr.produk_id
    JOIN subkategori sk    ON pr.subkategori_id = sk.subkategori_id
    JOIN kategori k        ON sk.kategori_id = k.kategori_id
    GROUP BY pr.produk_id
)
SELECT *
FROM CategoryProductSales
WHERE ranking_kategori <= 2
LIMIT 8;

4. LAG: Analisis Pertumbuhan MoM (Month-over-Month Growth)

Buat Apa Fungsi LAG Digunakan?

Fungsi LAG(omzet, 1) mengambil nilai omzet dari baris 1 langkah sebelum periode saat ini. Dengan membandingkan omzet bulan ini terhadap bulan lalu, kita bisa menghitung laju pertumbuhan bulanan (MoM Growth %) secara langsung dalam query SQL.

SQL Query
-- Menghitung omzet bulanan dan persentase pertumbuhan dibanding bulan sebelumnya
WITH MonthlyRevenue AS (
    SELECT 
        STRFTIME('%Y-%m', tanggal_pesanan) AS periode_bulan,
        SUM(total_bayar) AS omzet_bulanan
    FROM pesanan
    WHERE status_pesanan = 'Selesai'
    GROUP BY periode_bulan
)
SELECT 
    periode_bulan,
    omzet_bulanan,
    LAG(omzet_bulanan, 1) OVER (ORDER BY periode_bulan) AS omzet_bulan_lalu,
    ROUND(
        (CAST(omzet_bulanan - LAG(omzet_bulanan, 1) OVER (ORDER BY periode_bulan) AS REAL) 
        / LAG(omzet_bulanan, 1) OVER (ORDER BY periode_bulan)) * 100,
        1
    ) AS mom_growth_percent
FROM MonthlyRevenue;

5. Running Total: Akumulasi Omzet Berjalan

Konsep Running Total

SUM(total_bayar) OVER (ORDER BY tanggal_pesanan) menjumlahkan omzet secara kumulatif dari transaksi pertama hingga transaksi saat ini. Sangat berguna untuk melacak pencapaian target pendapatan toko sepanjang tahun (Year-to-Date / YTD).

SQL Query
-- Akumulasi total omzet toko secara real-time dari waktu ke waktu
SELECT 
    nomor_invoice,
    DATE(tanggal_pesanan) AS tgl_pesanan,
    total_bayar,
    SUM(total_bayar) OVER (ORDER BY tanggal_pesanan) AS running_total_omzet
FROM pesanan
WHERE status_pesanan = 'Selesai'
LIMIT 6;
