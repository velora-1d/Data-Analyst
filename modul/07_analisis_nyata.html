Studi Kasus Analisis Bisnis E-Commerce

Selamat datang di Capstone Project! Di modul pamungkas ini, Anda akan menggabungkan seluruh konsep SQL (Tipe Data, Filter, Agregasi, Multi-Table JOIN, CTE, dan Window Functions) untuk menjawab pertanyaan strategis yang dihadapi oleh C-Level dan Manajer E-Commerce.

1. Pengantar Analisis Bisnis Nyata

Peran Data Analyst bukan sekadar menjalankan query teknis, melainkan memberikan rekomendasi aksi bisnis (Actionable Insights) dari data mentah. Kita akan membedah 6 kasus manajerial di database e-commerce kita.

2. Kasus 1: Rekapitulasi Laba Bersih (Net Profit) & Margin (%)

Pertanyaan Manajerial: Berapa total uang kotor yang masuk (GMV), berapa modal pokok pengadaan barang (HPP), berapa biaya diskon yang dikeluarkan, dan berapa laba bersih final toko?

SQL Query
-- Rekapitulasi Finansial Laba Rugi Toko
SELECT 
    COUNT(DISTINCT p.pesanan_id)                                                       AS total_order_selesai,
    SUM(rp.subtotal)                                                                   AS omzet_kotor,
    SUM(p.potongan_diskon)                                                             AS total_diskon_diberikan,
    SUM(rp.jumlah * vp.harga_modal)                                                     AS total_hpp_modal,
    SUM(rp.subtotal) - SUM(p.potongan_diskon) - SUM(rp.jumlah * vp.harga_modal)      AS laba_bersih_final,
    ROUND(
        (CAST(SUM(rp.subtotal) - SUM(p.potongan_diskon) - SUM(rp.jumlah * vp.harga_modal) AS REAL) 
        / SUM(rp.subtotal)) * 100,
        2
    ) AS net_profit_margin_percent
FROM pesanan p
JOIN rincian_pesanan rp ON p.pesanan_id = rp.pesanan_id
JOIN variasi_produk vp  ON rp.variasi_id = vp.variasi_id
WHERE p.status_pesanan = 'Selesai';

3. Kasus 2: Top 5 Kategori Paling Menguntungkan

Pertanyaan Manajerial: Kategori produk mana yang memberikan sumbangan laba (profit) nominal terbesar bagi perusahaan?

SQL Query
-- Profitabilitas per Kategori Produk
SELECT 
    k.nama_kategori,
    SUM(rp.jumlah)                                     AS unit_terjual,
    SUM(rp.subtotal)                                   AS revenue_kategori,
    SUM(rp.subtotal) - SUM(rp.jumlah * vp.harga_modal) AS profit_kategori,
    ROUND(
        (CAST(SUM(rp.subtotal) - SUM(rp.jumlah * vp.harga_modal) AS REAL) / SUM(rp.subtotal)) * 100, 
        1
    ) AS profit_margin_percent
FROM rincian_pesanan rp
JOIN pesanan p         ON rp.pesanan_id = p.pesanan_id
JOIN variasi_produk vp ON rp.variasi_id = vp.variasi_id
JOIN produk pr         ON vp.produk_id = pr.produk_id
JOIN subkategori sk    ON pr.subkategori_id = sk.subkategori_id
JOIN kategori k        ON sk.kategori_id = k.kategori_id
WHERE p.status_pesanan = 'Selesai'
GROUP BY k.kategori_id
ORDER BY profit_kategori DESC
LIMIT 5;

4. Kasus 3: Segmentasi Pelanggan (RFM Analysis)

Pertanyaan Manajerial: Siapa saja pelanggan VIP (Champions) yang loyal dan menghasilkan nilai belanja tertinggi untuk diprioritaskan oleh tim CRM?

SQL Query
-- RFM Segmentation Pelanggan
WITH CustomerAgg AS (
    SELECT 
        pl.pelanggan_id,
        pl.nama_lengkap,
        pl.kota,
        MAX(p.tanggal_pesanan) AS transaksi_terakhir,
        COUNT(p.pesanan_id) AS total_transaksi,
        SUM(p.total_bayar)  AS total_pengeluaran
    FROM pelanggan pl
    JOIN pesanan p ON pl.pelanggan_id = p.pelanggan_id
    WHERE p.status_pesanan = 'Selesai'
    GROUP BY pl.pelanggan_id
)
SELECT 
    nama_lengkap,
    kota,
    total_transaksi,
    total_pengeluaran,
    CASE 
        WHEN total_pengeluaran >= 3000000 AND total_transaksi >= 3 THEN 'VIP Champion'
        WHEN total_pengeluaran >= 1500000 THEN 'Loyal Customer'
        ELSE 'Regular Customer'
    END AS customer_segment
FROM CustomerAgg
ORDER BY total_pengeluaran DESC
LIMIT 6;

5. Kasus 4: Evaluasi ROI Voucher Promo Diskon

Pertanyaan Manajerial: Berapa rasio uang yang dihasilkan dibanding nominal diskon yang kita bakar (Promo Burn Rate)?

SQL Query
-- Evaluasi Kinerja Kupon Promo
SELECT 
    vp.kode_voucher,
    vp.tipe_diskon,
    vp.nilai_diskon,
    COUNT(p.pesanan_id)   AS frekuensi_dipakai,
    SUM(p.potongan_diskon) AS total_biaya_diskon,
    SUM(p.total_bayar)     AS total_omzet_yang_dihasilkan
FROM pesanan p
JOIN voucher_promo vp ON p.voucher_id = vp.voucher_id
WHERE p.status_pesanan = 'Selesai'
GROUP BY vp.voucher_id
ORDER BY total_omzet_yang_dihasilkan DESC;

6. Kasus 5: Analisis Volume Logistik Kurir

SQL Query
-- Evaluasi Beban Logistik Pengiriman Ekspedisi
SELECT 
    ke.nama_kurir,
    ke.layanan,
    COUNT(p.pesanan_id)                           AS total_paket_dikirim,
    SUM(p.ongkos_kirim)                           AS total_ongkir,
    ROUND(AVG(p.total_berat_gram) / 1000.0, 2)      AS rata_rata_berat_kg
FROM pesanan p
JOIN kurir_ekspedisi ke ON p.kurir_id = ke.kurir_id
WHERE p.status_pesanan IN ('Dikirim', 'Selesai')
GROUP BY ke.kurir_id
ORDER BY total_paket_dikirim DESC;

7. Kasus 6: Inventory Alert (Stok Kritis Gudang < 20 Unit)

SQL Query
-- Monitoring SKU dengan sisa persediaan menipis
SELECT 
    g.nama_gudang,
    pr.nama_produk,
    vp.sku,
    vp.warna,
    vp.ukuran,
    sg.jumlah_stok
FROM stok_gudang sg
JOIN gudang g          ON sg.gudang_id = g.gudang_id
JOIN variasi_produk vp ON sg.variasi_id = vp.variasi_id
JOIN produk pr         ON vp.produk_id = pr.produk_id
WHERE sg.jumlah_stok < 20
ORDER BY sg.jumlah_stok ASC
LIMIT 8;
